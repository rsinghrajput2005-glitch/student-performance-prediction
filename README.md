# Student Performance Prediction

## Overview

This project predicts student mathematics scores using Machine Learning.

## Models Used

- Linear Regression
- Decision Tree
- Bagging Regressor
- Random Forest
- Gradient Boosting
- XGBoost

## Features

- Gender
- Race/Ethnicity
- Parental Education
- Lunch
- Test Preparation Course
- Reading Score
- Writing Score

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- XGBoost

## Results

Model comparison was performed using R² Score.
